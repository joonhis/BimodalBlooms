# Selecting_bimodal_blooms
Bloom selection code for “Seasonal Shifts in Phytoplankton Community Composition and Net Primary Production Efficiency during Spring and Fall Blooms”

Analysis_code directory: contains the code used to identify spring and fall blooms and to select regions exhibiting bimodal bloom characteristics based on seasonal chlorophyll-\textit{a} variability.
Model_set directory: contains the model configuration files and package options used for the numerical simulations in this study.
